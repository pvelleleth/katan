# Settler Frontend

The frontend application for [Settler](../README.md). Built with [SvelteKit](https://kit.svelte.dev/) and [Tailwind CSS](https://tailwindcss.com/), this app provides a responsive and reactive user interface for the strategy trading game.

## 🚀 Features

- **Interactive Game Board**: Built with modern Svelte 5 snippets and components.
- **Fast Navigation**: Fast, client-side routing via SvelteKit.
- **Modern Styling**: Styled with Tailwind CSS for a premium feel.
- **WebSocket Client**: Real-time communication with the game engine.
- **Authentication**: User management handled by [Better Auth](https://better-auth.com/).

## 🛠️ Installation

1.  [Install Bun](https://bun.sh/).
2.  Install dependencies:
    ```bash
    bun install
    ```
3.  Set up environment variables:
    ```bash
    cp .env.example .env
    ```
    (Configure your Supabase/database URLs).

## 🏗️ Development

To start the development server:

```bash
bun run dev
```

To run the check (TypeScript and Svelte validations):

```bash
bun run check
```

## 📁 Project Structure

- `src/routes/`: SvelteKit pages and API routes.
- `src/lib/`: Shared components and UI primitives.
- `src/lib/server/db/`: Database interaction and Drizzle schema.
- `drizzle/`: SQL migrations generated by Drizzle Kit.
